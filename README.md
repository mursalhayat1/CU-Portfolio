# Mursal Hayat — Full-Stack Developer Portfolio

A modern, high-performance developer portfolio inspired by award-winning editorial web design. Built with **React 18**, **TypeScript**, **Tailwind CSS**, and **GSAP** micro-interactions.

---

## ⚡ Features

- **Fluid Editorial Typography**: Custom masked split-line header animations powered by GSAP.
- **Interactive Project Hover Previews**: Custom cursor follower with smooth image reveal physics on hover.
- **Detailed Project Drawer**: Interactive modal views displaying system architecture, challenges, solutions, and impact metrics.
- **Client & Tech Marquee**: Seamless horizontal ticker animation.
- **Live Timezone Clock**: Dynamic real-time Toronto / Eastern Time (ET) indicator in the footer.
- **Responsive Navigation**: Mobile slide-out drawer menu with smooth scrolling.
- **SEO & Social Share Ready**: Open Graph meta tags and Schema.org JSON-LD structured data for rich social cards.

---

## 🛠️ Tech Stack

- **Framework**: React 18 (Vite)
- **Language**: TypeScript
- **Styling**: Tailwind CSS, PostCSS
- **Animations**: GSAP (GreenSock) & ScrollTrigger
- **Icons**: Lucide React & inline SVGs

## 🚀 Getting Started Locally

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or pnpm or bun

### Installation & Run

```bash
# 1. Install dependencies
npm install

# 2. Start the local development server
npm run dev

# 3. Build for production
npm run build

# 4. Preview the production build
npm run preview
```

## 🌐 Deploying Your Portfolio (Free Hosting)

Before sharing your website on LinkedIn, deploy it to a live public URL.

### Option 1: Vercel (Recommended)
1. Push your code to a GitHub repository.
2. Go to [vercel.com](https://vercel.com) and sign in with GitHub.
3. Click **Add New Project** and import your portfolio repository.
4. Keep the default settings (Framework Preset: **Vite**, Build Command: `npm run build`, Output Directory: `dist`).
5. Click **Deploy**. Your portfolio will be live at `https://your-name.vercel.app` (you can also attach a custom domain like `mursalhayat.dev`).

### Option 2: Netlify
1. Log in to [netlify.com](https://netlify.com).
2. Connect your GitHub repository.
3. Set the build command to `npm run build` and publish directory to `dist`.
4. Click **Deploy Site**.

## 💼 How to Publish & Showcase Your Portfolio on LinkedIn

Follow these steps to maximize visibility, recruiters' attention, and network reach on LinkedIn.

### 1. Add to Your LinkedIn Profile Header Link
1. Go to your LinkedIn Profile and click the **Pencil icon** (Edit Intro) in the top card.
2. Scroll to the bottom to the **Custom button** or **Website** field.
3. Paste your live portfolio URL:
   - **URL**: `https://your-portfolio-domain.com`
   - **Link text**: `Visit Portfolio ⚡` or `mursalhayat.dev`
4. Click **Save**. This places a prominent clickable button right under your name and headline.

---

### 2. Showcase in the "Featured" Section
The Featured section sits prominently above your Experience section on LinkedIn.

1. On your profile, scroll to the **Featured** section (if not visible, click **Add profile section** > **Recommended** > **Add featured**).
2. Click the **+** icon and select **Add a link**.
3. Paste your live portfolio URL.
4. Customize the preview:
   - **Title**: `Mursal Hayat — Full-Stack Developer & Software Engineer Portfolio`
   - **Description**: `Interactive portfolio showcasing distributed systems, high-throughput microservices, and modern web architectures with React, TypeScript, and Node.js.`
5. Click **Save**.

---

### 3. Add to the "Projects" Section
1. Under **Add profile section** > **Additional** > **Add projects**.
2. **Project Name**: `Personal Portfolio & Architecture Showcase`
3. Check **I am currently working on this project**.
4. **Associated with**: Your current freelance / full-stack role or leave unassociated.
5. Add skills: `React.js`, `TypeScript`, `Node.js`, `Distributed Systems`, `Tailwind CSS`.
6. Include your live deployment URL.
